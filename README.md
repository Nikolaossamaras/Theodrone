# Theodrone
> Theodrone is small drone roughly 130mm*130mm*30mm

# What is it
it's a basic drone that you can later on equip with a thermal or a normal camera so you can make recording and check the situation in Forests so they want catch fire.

# Why i built it

Where i live forest fires are something often in summer , so i with this drone you can check the situation in a Forest as it's equiped with a thermal camera.
